# 01 - Components, Directives & Pipes

Demonstrates:
- Component creation (`UserCardComponent`), property binding, event binding, two-way binding (`[(ngModel)]`)
- `@Input`/`@Output` parent-child communication
- Lifecycle hooks: `ngOnInit`, `ngOnChanges`, `ngOnDestroy` (see browser console when running)
- Structural directives: `*ngIf`, `*ngFor`, `*ngSwitch`
- Attribute directives: `ngClass`, and a hand-written custom directive `appHighlight`
- Built-in pipes: `date`, `currency`, `uppercase`, and a custom `truncate` pipe

## Run
```bash
npm install
npm start
```
Then open `http://localhost:4200`.
